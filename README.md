# 👥 HR Workforce & Attrition Analysis Dashboard | Power BI

1. Project Title / Headline

👥 HR Workforce & Attrition Analysis Dashboard | Power BI**

2. Short Description / Purpose

This project analyzes employee workforce data to understand employee attrition, workforce distribution, demographics, job satisfaction, experience, and departmental performance. The interactive Power BI dashboard provides HR teams with data-driven insights to monitor workforce trends, identify attrition patterns, and understand factors associated with employee turnover.

The dashboard helps organizations improve employee retention, workforce planning, HR decision-making, and organizational performance.

3. Tech Stack

📊 **Power BI** – Dashboard development & data visualization  
🧹 **Power Query** – Data cleaning & transformation  
📐 **DAX** – Measures, KPIs & calculations  
🐍 **Python** – Data cleaning & exploratory data analysis  
📗 **Pandas / NumPy / Matplotlib** – Data processing & analysis  
📁 **File Formats** – `.pbix` for Power BI dashboard & `.png` for dashboard preview

7. Data Cleaning & Preparation

The employee dataset was prepared for analysis using data-cleaning and transformation techniques.

The main steps included:

- Checking dataset shape and structure
- Checking missing and inconsistent values
- Removing duplicate records
- Standardizing column names and values
- Checking categorical variables
- Validating numerical fields
- Checking employee and department information
- Preparing attrition-related fields
- Creating calculated columns and measures
- Preparing the final dataset for Power BI analysis

Power Query was used to perform data transformation and preparation before developing the interactive dashboard.

9. Exploratory Data Analysis

The project includes exploratory analysis such as:

👥 **Workforce Analysis**  
Analyzes employee distribution across departments, job roles, age groups, and other workforce categories.

📉 **Attrition Analysis**  
Examines employee attrition patterns and compares employees who stayed with employees who left.

🏢 **Department Analysis**  
Compares workforce size and attrition across different departments.

👨‍💼 **Job Role Analysis**  
Analyzes employee distribution and attrition across different job roles.

😊 **Satisfaction Analysis**  
Evaluates job satisfaction, environment satisfaction, and work-life balance.

⏳ **Experience Analysis**  
Analyzes employee tenure and overall work experience to understand workforce composition.

💰 **Income Analysis**  
Examines income distribution across employee groups, departments, and job levels.
